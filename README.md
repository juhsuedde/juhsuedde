## Projetos

### ⭐ [TokyoTrip Hub](https://github.com/juhsuedde/tokyo-trip-hub)

PWA colaborativo de diário de viagem com arquitetura offline-first (IndexedDB + Workbox). Integra OpenAI Whisper para transcrição de áudio e GPT-4 Vision para OCR e auto-categorização de fotos. Colaboração em tempo real via Socket.io para até 4 usuários; filas assíncronas com Redis + Bull; containerização completa com Docker Compose.

`React 18` `Node.js` `PostgreSQL` `Prisma` `Redis` `Bull` `Socket.io` `OpenAI` `PWA` `Docker`

`React` `TypeScript` `Supabase` `Tailwind CSS` `PWA` `OAuth`
